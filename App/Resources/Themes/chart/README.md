# chart — テーマ「海図（1 画面）」（F-63）

`theme.json` の `"screen": "chart"` で、タブの 5 画面の代わりに海図の 1 画面（`App/Sources/Features/Chart/`）を出すテーマ。

- `thumb.jpg`：設定 > テーマ のカードの絵（予想図 `docs/ui/chart_preview.jpg` から切り出し）
- 画面の素材（背景・ボタン・計器）は `App/Resources/ChartUI/`、港の海図は `App/Resources/Charts/`
- `colors` は「≡」から開くログ・図鑑・設定などの配色
