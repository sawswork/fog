# sylphie — 森の魔法陣（F-58）

開発者のモック画像を **そのまま再現した 1 枚絵** を背景にし、泡・魔法陣・地図台の位置に実データの部品を重ねるテーマ。タブバーも下の 5 つの印も無い。

画像は Gemini `gemini-3-pro-image-preview`（ネイティブ API、参考画像つき、2K）で生成（2026-11-09）。
背景はモック画像を参照させ「UI の文字・数字・アイコン・下の 5 つの印だけを消す」編集で作った。シルフィの顔・服・立体の地図台・透明な泡はモックのまま。

| ファイル | 内容 | 置き方 |
| --- | --- | --- |
| `bg_home.jpg` | モックの再現（シルフィ込み、1206×2160） | 全画面に `fill`、`motion: drift`（ごくゆっくり寄って戻る） |
| `tab_camera.png` / `tab_guide.png` | 撮影・図鑑のボタンの印（透過） | `button` 部品の画像（右中段） |
| `bg_log.jpg` `bg_guide.jpg` `bg_sheet.jpg` | 他の画面の背景 | 従来どおり |

効果の層（画像なし）：`fireflies`（光の粒 30）、`sparkles`（きらめき 14、金）、`leaves`（舞う葉 8）。

部品の座標は背景の泡・魔法陣に合わせてある（`docs/ui/sylphie_layout_preview.png`）。
- 釣れ率 → 魔法陣の内側、グラフ → 左の泡、3 時間ごとの表 → 右の泡、釣果情報の 1 行 → 泡の下、直近の釣果 → 左中段、週 → 右中段
- 下の地図台は絵（タップで釣り場画面）。実際の地図の部品を重ねたいときは `miniMap` を `rect: [0.03, 0.71, 0.93, 0.19]` で足す

シルフィだけを浮かせたい（`motion: float`）ときは、背景をシルフィ無しの版に差し替えて切り抜きの `char_home.png` を層に足す（生成済みの素材は開発者へ渡す）。
マゼンタ背景の素材は `scripts/theme_chroma_key.py` で透過にする。
