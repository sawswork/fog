# ram — 雨夜の提灯（F-58、2026-11-11）

開発者が添付した絵（桃色の髪の少女、赤い和傘、雨の夜の鳥居と提灯、桜）をもとにしたテーマ。レムのテーマ（`rem`）と同じ作りで、**標準レイアウト**のまま配色・明朝の数字・薄い枠・画像で見た目を変える。色は黒・灰・濃い桃色の単色調。
画像はすべて Gemini `gemini-3-pro-image-preview` に添付の絵を参考画像として渡して生成した（2K）。本人利用のみのアプリ内で使う。

| ファイル | 内容 |
| --- | --- |
| `bg_home.jpg` | ホームの背景。ラムの顔は左上（釣れ率の円の左）、提灯は円の右、鳥居・桜・雨。姿勢と服は元の絵のまま。顔より下（28% から）は暗くしてある |
| `ring_home.png` | 円に沿う赤い組紐と桜の飾り枠 |

作り方の注意

- 配色が桃色なので、切り抜きはすべて**緑背景**で作り `scripts/theme_green_key.py` で抜いた（マゼンタ抜きは絵の桃色まで抜いてしまう）。印の内側に残った黄緑は暗い赤に置き換えた
- ホームの背景は、元の絵を文字なしで再現した 1 枚を 70% に縮めて左上に置き（縁は 150 px ぼかす）、残りを描き足させた（`rem` と同じ手順）
- `style` は `rem` と同じ考え方：枠を透かす（`panel: "#12060B3F"`、ぼかし無し）、`borderColor: "#FFB3C878"`、`captureFill: "#4A1028"`、`glowColor: "#12060B"`。潮の色（`sea`）は単色調に合わせて淡い桃色
- 配置と色の予想図は `docs/ui/ram_preview.jpg`（ホームの拡大は `docs/ui/ram_preview_home.png`）
