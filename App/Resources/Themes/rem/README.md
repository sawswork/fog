# rem — 月夜の鳥居（F-58、2026-11-10）

開発者が添付した絵（青い髪の少女、月夜の森と鳥居、青く光る花びら、赤い糸）をもとにしたテーマ。**標準レイアウト**のまま、配色・明朝の数字・薄い枠・画像で見た目を変える（`home` の配置は持たない）。
画像はすべて Gemini `gemini-3-pro-image-preview` に添付の絵を参考画像として渡して生成した（2K）。本人利用のみのアプリ内で使う。

作り方の注意

- `style`：`glass: true` + `glassBlur: false` + `glassOpacity: 1`、`panel: "#060A183D"`（紺 24%）。フェルンと同じく**枠を透かして背景を見せる**（2026-11-10 開発者「背景が見えないのでフェルンのテーマみたいに枠をすかして」）。`borderColor: "#AACDFF78"`（淡い氷色の細い枠）、`captureFill: "#101E46"`、`glowColor: "#060A1A"`
- ホームの背景の作り方：1 枚絵は顔が中央に来て円に隠れるので、出来の良い 1 枚を 52% に縮めて左上に置き（縁は 150 px ぼかす）、残りを Gemini に描き足させた。縁をぼかさないと継ぎ目が残る
- スカートは元の絵と同じ短い丈（開発者の指摘：長すぎる → 元の絵を参考に添えて下半身だけ描き直し）。血と傷は描かない
- キャラクターの切り抜きはピンクのリボンがあるので**緑背景**で作り、`scripts/theme_green_key.py` で抜いた（マゼンタ抜きだとリボンが欠ける）。小物はマゼンタ背景で `scripts/theme_chroma_key.py`
- 透過 PNG は四辺に 5〜6% の透明な余白を足してある（アプリが縁の色で背景を判定するため）
- 配置と色の予想図は `docs/ui/rem_preview.jpg`（ホームの拡大は `docs/ui/rem_preview_home.png`）
